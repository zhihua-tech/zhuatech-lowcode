# 企业低代码应用开发平台企业能力

## 领域覆盖

- **应用空间**：管理应用、业务域、负责人、成员和环境
- **数据模型**：设计实体、字段、校验、索引、关系和数据权限
- **智能表单**：配置布局、字段、联动、校验、权限和移动端适配
- **页面设计**：通过组件、主题和数据源构建管理端与门户页面
- **流程编排**：配置节点、条件、审批人、超时和撤回规则
- **业务规则**：维护表达式、决策表、触发器和服务端校验
- **连接器**：连接API、数据库、消息、文件和企业身份平台
- **版本管理**：保存草稿、差异、依赖、快照和回滚点
- **发布治理**：执行安全、权限、性能、命名和上线门禁

## 横向控制基线

- ADMIN 与 OPERATOR 权限分离，管理员审批由服务端强制校验；
- 模块白名单、字段约束、唯一编号、乐观锁和合法状态迁移；
- 企业控制项支持组织、期间、责任人、风险、期限和幂等键；
- 治理驾驶舱按组织与账期汇总在途、逾期、临期、证据缺口、同步失败和办结率；
- 批量提交与批量审批限制在 100 条以内并使用单事务，任一记录非法时整体回滚；
- 管理员可冻结或重新开放组织账期，冻结状态由服务端拦截所有关键业务变更；
- 经办与复核职责分离，办结前至少登记一份带 SHA-256 的业务凭证；
- 外部系统同步保存成功、失败、回执编号和审计详情；
- 支持组合检索、分页、逾期筛选、CSV 导出、评论与时间线；
- `/api/domain/decision` 对企业低代码应用开发平台关键场景返回决策、0–100评分、计算指标和处置动作；
- prod profile 对默认账号密码、数据库口令和不安全跨域来源执行启动门禁。

## 生产适配

真实 `IAM`、IAM、消息、对象存储和第三方供应商接口只预留集成边界，由部署企业自行配置。生产上线前必须完成权限矩阵、数据映射、容量压测、灾备演练、安全评估与用户验收。
